# Подключение через Hiddify

Установите Hiddify, скопируйте персональный ключ из бота и добавьте его через **«+» → «Из буфера обмена / Clipboard»**. После этого выберите профиль и нажмите большую кнопку подключения.

| --- | --- | --- |
| Android | [Пошагово](android.md) | [Google Play](https://play.google.com/store/apps/details?id=app.hiddify.com) |
| iPhone / iPad | [Пошагово](ios.md) | [App Store](https://apps.apple.com/app/hiddify-proxy-vpn/id6596777532) |
| Windows | [Пошагово](windows.md) | [Установщик x64](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-Windows-Setup-x64.exe) |
| macOS | [Пошагово](macos.md) | [DMG](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-MacOS.dmg) |
| Linux | [Пошагово](linux.md) | [AppImage x64](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-Linux-x64-AppImage.AppImage) |
| Android TV / Google TV | [Пошагово](tv.md) | [Universal APK](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-Android-universal.apk) |

Если соединение не работает или видео останавливается, начните с [проверки подключения](troubleshooting.md).

## Какой ключ добавлять

**Базовый тариф — около 50 ₽ в месяц:** Hysteria 2, один одновременно подключённый экземпляр клиента. Можно открыть много приложений и сайтов на этом устройстве. Перед переходом на другое устройство отключите Hiddify на первом.

**Полный тариф — около 100 ₽ в месяц:** Hysteria 2 и VLESS + REALITY, количество устройств не ограничено. Добавьте обе выданные ботом ссылки по очереди. Если одна не работает в текущей сети, отключите соединение, выберите второй профиль и подключитесь заново.

Списание почасовое: **0,07 ₽/час** и **0,14 ₽/час** соответственно; за 30 суток активной подписки получится **50,40 ₽** и **100,80 ₽**. Оплата зависит от состояния подписки, а не от открытого соединения: отключение Hiddify не останавливает её. Чтобы остановить оплату, приостановите доступ в разделе «Подписка» бота. Это не авансовая оплата фиксированного 30-дневного периода. Сейчас автосписания остаются отключёнными до отдельного запуска.

Персональный ключ — это ссылка вида `hysteria2://…` / `hy2://…` или `vless://…`. Копируйте её целиком, без подписи сообщения. Выпуск ключа бесплатный. Ссылка и QR дают доступ к VPN: отправляйте в поддержку описание ошибки, скрыв ключ.

Если бот выдал **ссылку подписки `https://…`**, импортируйте её тем же способом. Подписка может содержать сразу несколько вариантов соединения; её можно обновлять в Hiddify. Используйте выданную ссылку целиком и не меняйте схему вручную. Для нашего сервиса рекомендуются HTTPS-подписки. Настройки транспорта уже находятся в персональной ссылке; вручную менять SNI, REALITY, TLS и порты не требуется.

Полный локальный preview с 17 настоящими изображениями, включая наши 8 снимков Linux 5.5.5 и 2 снимка страниц магазинов, сохранён отдельно.
