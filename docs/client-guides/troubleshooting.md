# Проверка подключения и скорости

Начните с короткой проверки на том же устройстве и в той же сети. Зелёная кнопка показывает состояние клиента; открывающееся видео подтверждает работу конкретного сервиса.

## Нет профиля или импорт выдаёт ошибку

1. Повторно получите профиль нужного сервиса. **Hysteria:** сохраните `vpn-by-andriyshkoy-hysteria.json` или скопируйте весь профиль: первую строку `// profile-title` и JSON целиком; не выбирайте только пароль или часть документа. **VLESS + REALITY:** скопируйте всю ссылку `vless://…`. Не добавляйте подпись сообщения.
2. Для файла Hysteria выберите **«+» → Файл / File**. Для целого профиля или ссылки VLESS используйте **«+» → Из буфера обмена / Clipboard**. JSON не является HTTPS-адресом подписки; не вставляйте его в поле URL. Не удаляйте параметры TLS и не включайте `insecure`, чтобы обойти ошибку сертификата: получите свежий профиль в боте.
3. Если ссылка подписки не загружается, проверьте обычный интернет и обновите профиль кнопкой обновления. После замены ключа в боте старый профиль может перестать работать: импортируйте новый JSON Hysteria или новую ссылку VLESS. Не отправляйте полный ключ в общий чат.

## Подключение не устанавливается

4. Убедитесь, что интернет работает без VPN. Отключите другой VPN. На базовом тарифе отключите этот ключ на предыдущем устройстве. Количество вкладок и сетевых запросов внутри одного клиента этим ограничением не считается.
5. Проверьте автоматические дату и время, системное разрешение VPN, затем обновите Hiddify из официального источника. На Windows для полного VPN нужны соответствующие права; на macOS проверьте системный запрос расширения; на Linux — сообщение о правах/интерфейсе.
6. На полном тарифе отключитесь, выберите второй транспорт и повторите: **Hysteria 2 → VLESS + REALITY** или обратно. Hysteria использует UDP; ограничения конкретной сети могут влиять на него иначе, чем на VLESS. Наличие второго транспорта даёт вариант переключения, но не обещает работу при любой блокировке.
7. Сравните Wi-Fi и мобильную сеть. Запишите результат отдельно для каждой. Если не работает только одна сеть, это полезнее для диагностики, чем многократная переустановка приложения.

## Подключено, но приложения или видео не работают

8. На компьютере проверьте **Service mode → VPN**: System proxy может охватывать только часть программ. Перезапустите проверяемое приложение после смены режима.
9. Откройте YouTube, запустите ролик, вручную выберите 720p/1080p и перемотайте. Затем загрузите видео/файл в Telegram. Проверьте 5–10 минут непрерывного воспроизведения. Отметьте, где обрыв: сразу, после перемотки или после блокировки экрана.
10. Для проверки выхода в NL сравните внешний IP до и после соединения в привычном сервисе проверки IP. Такой сайт видит IP посетителя; проверка добровольная. На полном VPN проверьте и браузер, и отдельное приложение. Изменившийся IP не доказывает отсутствие всех возможных DNS/IPv6-утечек.
11. Если тормозит, сравните оба транспорта на одной сети и при одинаковом качестве видео; повторите в другое время. Один тест скорости не равен устойчивому просмотру видео. Не меняйте сразу несколько настроек.

## Обрывы в фоне или после сна

12. Android: разрешите фоновую работу и исключение из оптимизации батареи для Hiddify. Другие платформы: после сна дождитесь восстановления сети и переподключитесь кнопкой клиента. Автовосстановление зависит и от ОС, и от сети.
13. Подписку можно обновить в Hiddify. Отдельный JSON-файл или ссылка VLESS сами по себе не превращаются в обновляемую подписку и не гарантирует автоматическое переключение между двумя отдельно добавленными профилями.

## Что передать поддержке

Укажите модель устройства, ОС, версию Hiddify, провайдера/тип сети, город, время с часовым поясом, выбранный транспорт и точный текст ошибки. Приложите снимок экрана с **закрытыми ключом и QR**. Напишите, работает ли второй транспорт и другая сеть; для видео — качество и момент остановки. Рабочий ключ, токен подписки и полный лог с личными данными в общий чат не отправляйте.
