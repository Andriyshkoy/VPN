# Hiddify на Android TV и Google TV

В [релизе Hiddify 5.5.5](https://github.com/hiddify/hiddify-app/releases/tag/v5.5.5) официально добавлена поддержка **Android TV** и ввод подписки через QR, который сканируют телефоном. Это инструкция для Android TV / Google TV. Поддержка Apple TV, Samsung Tizen и LG webOS в проверенном релизе не заявлена.

## Установить

1. На телевизоре откройте Google Play и найдите **Hiddify**. [Официальная страница приложения](https://play.google.com/store/apps/details?id=app.hiddify.com), package `app.hiddify.com`. Наличие кнопки установки зависит от модели и магазина устройства.
2. Если приложение не предлагается для TV, используйте [официальный universal APK](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-Android-universal.apk), передав файл на телевизор привычным способом. Для ручной установки Android может запросить разрешение установки из используемого файлового менеджера. Требуется Android 7+.
3. Запустите Hiddify, выберите язык и фактический регион.

## Передать доступ с телефона

4. Подключите телефон и TV к одной домашней сети. На телевизоре откройте **«+»** и оставьте окно добавления открытым. Отсканируйте **QR на экране телевизора** телефоном: откроется локальная страница самого TV. Для Hysteria вставьте весь JSON из бота, включая внешние фигурные скобки; для VLESS — всю ссылку `vless://…`. Отправьте профиль. Затем **подтвердите импорт на телевизоре**. Эти шаги сверены с [реализацией TV-импорта 5.5.5](https://github.com/hiddify/hiddify-app/blob/v5.5.5/lib/features/profile/add/phone_import/phone_import_panel.dart).
5. Если камера телефона не считывает QR, откройте в его браузере **полный адрес, показанный под QR**, включая порт и код в конце. Это временный локальный адрес передачи, а не URL подписки. Если страница не открывается, проверьте общую сеть и отсутствие изоляции устройств в гостевом Wi-Fi. Для JSON Hysteria также можно передать `hiddify-hysteria.json` на TV и выбрать **«+» → Файл / File**, либо вставить весь JSON через Clipboard. Ссылку VLESS добавляйте через Clipboard. Не вставляйте JSON в поле URL ручной HTTPS-подписки. После импорта закройте окно добавления.
6. Выберите добавленный профиль, режим **VPN**, затем кнопку подключения. Подтвердите системный запрос Android на создание VPN. Дождитесь **Connected**.
7. Проверьте ролик в приложении YouTube: сначала запуск, затем перемотку, затем 5–10 минут воспроизведения. Телевизор, телефон и Wi-Fi могут по-разному влиять на скорость; сравнивайте их на одной сети.
8. На базовом тарифе отключите VPN на телефоне, прежде чем пользоваться телевизором. На полном тарифе при недоступности Hysteria попробуйте VLESS + REALITY.

**Проверка иллюстраций:** реального снимка TV-интерфейса текущей версии в этой подготовке нет. Мы не подменяем его Android-телефоном или макетом. QR-сценарий подтверждён официальным релизом и исходниками, но не пройден на физическом TV; точные подписи кнопок нужно сверить на модели пользователя.
