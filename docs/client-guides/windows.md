# Hiddify на Windows

Поддерживаются **Windows 10 1809+ и Windows 11, x64**. Для всего компьютера нужен режим **VPN**; режим System proxy может охватывать только приложения, использующие системный прокси.

## Установить

1. Скачайте [официальный EXE-установщик x64](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-Windows-Setup-x64.exe). Дополнительные варианты: [Microsoft Store](https://apps.microsoft.com/detail/9pdfnl3qv2s5), [portable ZIP](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-Windows-Portable-x64.zip), [страница релизов](https://github.com/hiddify/hiddify-app/releases/latest).
2. Запустите установщик, подтвердите обычный запрос Windows и завершите мастер установки. Проверяйте, что файл скачан из официального релиза Hiddify. Если Windows сообщает о вредоносном файле или подмене подписи, не отключайте защиту: сохраните точный текст сообщения для поддержки.

![Официальный старый мастер установки Hiddify Next на Windows: каталог установки и кнопка Next](https://github.com/hiddify/Hiddify-Server/assets/125398461/7196a86f-3f74-4177-b611-19b484e0da9a)

*Официальная [инструкция Hiddify](https://hiddify.com/app/How-to-install-Hiddify-app/), реальный установщик Windows **0.6.0+600**. В актуальном установщике окна и значок могут отличаться.*

3. Откройте Hiddify, выберите русский язык и свой фактический регион. Для режима VPN полностью завершите приложение через значок в трее, затем запустите **правой кнопкой → Запуск от имени администратора**. Подтвердите запрос UAC.

![Меню Windows с командой Run as administrator для Hiddify](https://github.com/hiddify/Hiddify-Server/assets/125398461/9db385ec-8aba-47f5-a5b7-d2c34899fbc1)

*Официальный снимок Windows из [руководства Hiddify](https://hiddify.com/app/How-to-use-Hiddify-app/), старая версия Hiddify Next. Показана команда запуска с правами администратора.*

## Добавить ключ и включить VPN

4. В боте получите профиль сервиса. Для **Hysteria** сохраните `hiddify-hysteria.json` и откройте его в Hiddify через **Главная / Home → «+» → Файл / File**. Если JSON показан текстом, скопируйте его целиком, включая внешние фигурные скобки, и используйте **«+» → Из буфера обмена / Clipboard**. Для **VLESS + REALITY** скопируйте всю ссылку `vless://…` и импортируйте через Clipboard. На полном тарифе добавьте два сервиса отдельными профилями.
5. Откройте **Настройки / Settings → Inbound → Service mode → VPN**. В некоторых раскладках тот же выбор доступен через быстрые настройки на главной. Старый переключатель **Enable TUN** в новых версиях удалён: искать его не нужно.
6. Выберите профиль и нажмите большую кнопку подключения. Дождитесь **Connected / Подключено**.
7. Откройте видео в браузере, затем проверьте загрузку файла или видео в Telegram Desktop. Если работает только браузер, ещё раз проверьте режим **VPN** и запуск с правами администратора.
8. Для отключения нажмите кнопку подключения ещё раз. Перед запуском другого VPN отключите Hiddify. На базовом тарифе отключайте предыдущее устройство перед подключением следующего.

Если был выбран только **System proxy**, приложение, игнорирующее системный прокси, может выходить напрямую. Для проверки полного туннеля нужен именно VPN.
