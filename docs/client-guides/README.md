# Подключение через Hiddify

Установите Hiddify и получите профиль нужного сервиса в боте. **Hysteria** выдаётся JSON-файлом: сохраните `vpn-by-andriyshkoy-hysteria.json` и выберите **«+» → «Файл / File»**. Если бот показал JSON текстом, скопируйте весь профиль: первую строку `// profile-title` и JSON целиком и выберите **«+» → «Из буфера обмена / Clipboard»**. **VLESS + REALITY** добавляется целой ссылкой `vless://…` через Clipboard. Затем выберите добавленный профиль и подключитесь.

## Какой тариф выбрать

**BASIC — 50 ₽ в месяц.** Для Instagram и других повседневных задач на одном устройстве начните с этого тарифа. Включён Hysteria 2; одновременно можно подключить одно устройство. Перед переходом на другое отключите Hiddify на первом.

**PLUS — 100 ₽ в месяц.** Для более удобного использования на телефоне, компьютере и других устройствах. Количество устройств не ограничено, в подписку входят Hysteria 2 и VLESS + REALITY — два способа подключения.

### Зачем два протокола

Разные сети могут по-разному пропускать VPN-трафик. В PLUS есть запасной вариант: если один протокол перестал подключаться, попробуйте второй. Это удобно, когда вы меняете Wi-Fi на мобильный интернет или оператор вводит новые ограничения.

Можно начать с Hysteria. Добавьте оба выданных ботом профиля в Hiddify: JSON Hysteria и ссылку VLESS. Если соединение не устанавливается, отключитесь, выберите другой профиль и подключитесь заново. Переключение выполняется вручную; наличие двух профилей не включает автоматическую ротацию.

Одна подписка действует на аккаунт. Выпуск и замена ключей бесплатны. Чтобы остановить оплату, приостановите доступ в разделе «Подписка» бота: отключение Hiddify само по себе не приостанавливает подписку. Сейчас автосписания выключены.

Для **Hysteria** используйте только выданный ботом JSON-профиль. В нём уже задана проверка сертификата сервера; не удаляйте параметры TLS и не включайте `insecure`. Старую текстовую ссылку Hysteria для Hiddify замените новым JSON из бота. Для **VLESS + REALITY** скопируйте всю ссылку `vless://…` без подписи сообщения. Выпуск профиля бесплатный. JSON и ссылка содержат доступ к VPN: не публикуйте их и скрывайте содержимое на снимках экрана.

Если бот выдал **ссылку подписки `https://…`**, импортируйте её тем же способом. Подписка может содержать сразу несколько вариантов соединения; её можно обновлять в Hiddify. Используйте выданную ссылку целиком и не меняйте схему вручную. Для нашего сервиса рекомендуются HTTPS-подписки. Настройки транспорта уже находятся в готовом профиле; вручную менять SNI, REALITY, TLS и порты не требуется.
