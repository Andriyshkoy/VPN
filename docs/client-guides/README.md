# Подключение через Hiddify

Установите Hiddify и получите профиль нужного сервиса в боте. **Hysteria** выдаётся JSON-файлом: сохраните `hiddify-hysteria.json` и выберите **«+» → «Файл / File»**. Если бот показал JSON текстом, скопируйте его целиком, включая внешние фигурные скобки, и выберите **«+» → «Из буфера обмена / Clipboard»**. **VLESS + REALITY** добавляется целой ссылкой `vless://…` через Clipboard. Затем выберите добавленный профиль и подключитесь.

## Какой профиль добавлять

**Базовый тариф — около 50 ₽ в месяц:** Hysteria 2, один одновременно подключённый экземпляр клиента. Можно открыть много приложений и сайтов на этом устройстве. Перед переходом на другое устройство отключите Hiddify на первом.

**Полный тариф — около 100 ₽ в месяц:** Hysteria 2 и VLESS + REALITY, количество устройств не ограничено. Добавьте оба выданных ботом профиля по очереди: JSON Hysteria и ссылку VLESS. Если одна не работает в текущей сети, отключите соединение, выберите второй профиль и подключитесь заново.

Списание почасовое: **0,07 ₽/час** и **0,14 ₽/час** соответственно; за 30 суток активной подписки получится **50,40 ₽** и **100,80 ₽**. Оплата зависит от состояния подписки, а не от открытого соединения: отключение Hiddify не останавливает её. Чтобы остановить оплату, приостановите доступ в разделе «Подписка» бота. Это не авансовая оплата фиксированного 30-дневного периода. Сейчас автосписания остаются отключёнными до отдельного запуска.

Для **Hysteria** используйте только выданный ботом JSON-профиль. В нём уже задана проверка сертификата сервера; не удаляйте параметры TLS и не включайте `insecure`. Старую текстовую ссылку Hysteria для Hiddify замените новым JSON из бота. Для **VLESS + REALITY** скопируйте всю ссылку `vless://…` без подписи сообщения. Выпуск профиля бесплатный. JSON и ссылка содержат доступ к VPN: не публикуйте их и скрывайте содержимое на снимках экрана.

Если бот выдал **ссылку подписки `https://…`**, импортируйте её тем же способом. Подписка может содержать сразу несколько вариантов соединения; её можно обновлять в Hiddify. Используйте выданную ссылку целиком и не меняйте схему вручную. Для нашего сервиса рекомендуются HTTPS-подписки. Настройки транспорта уже находятся в готовом профиле; вручную менять SNI, REALITY, TLS и порты не требуется.
