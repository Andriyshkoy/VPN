# Hiddify на macOS

Для проверенного релиза **5.5.5** ориентируемся на **macOS 12+**, Intel или Apple Silicon: в [проекте этого релиза](https://github.com/hiddify/hiddify-app/blob/v5.5.5/macos/Runner.xcodeproj/project.pbxproj) задан deployment target 12.0. На старой странице установки ещё встречается 10.15; для текущей сборки этот минимум не используем.

## Установить

1. Скачайте [официальный DMG](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-MacOS.dmg) или [PKG-установщик](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-MacOS-Installer.pkg). Для Mac здесь используем отдельное desktop-приложение. iOS-приложение в App Store помечено Apple как **Not verified for macOS**.
2. Для DMG откройте загруженный образ, перетащите Hiddify в **Программы / Applications**. После копирования запускайте приложение из «Программ», а не из открытого образа.

![Окно DMG Hiddify на macOS: приложение перетаскивают в Applications](https://github.com/hiddify/Hiddify-Server/assets/125398461/07fa37b8-fc37-4613-b148-2eb932a3d53a)

*Реальный официальный снимок macOS из [инструкции Hiddify](https://hiddify.com/app/How-to-install-Hiddify-app/), старая версия HiddifyNext. Точная версия на изображении не указана.*

3. Если macOS блокирует открытие скачанного приложения, сначала убедитесь, что файл получен по официальной ссылке. Используйте штатную команду открытия в настройках **Конфиденциальность и безопасность / Privacy & Security**, если система предлагает её для Hiddify. Общую защиту macOS отключать не требуется.

![Старое окно безопасности macOS с кнопкой Open Anyway для HiddifyNext](https://github.com/hiddify/Hiddify-Server/assets/125398461/97fa1692-5eb2-436c-9070-804a71c3bc81)

*Официальный исторический снимок macOS. В современных версиях macOS этот раздел выглядит иначе; это пример разрешения запуска, **не** разрешение VPN/system extension.*

## Добавить профиль и разрешить VPN

4. При первом запуске выберите язык и фактический регион. Для **Hysteria** сохраните выданный ботом `hiddify-hysteria.json`; в Hiddify откройте **Главная / Home → «+» → Файл / File** и выберите его. Можно скопировать весь JSON, включая внешние фигурные скобки, и использовать **«+» → Из буфера обмена / Clipboard**. Для **VLESS + REALITY** скопируйте всю ссылку `vless://…` и используйте Clipboard. На полном тарифе добавьте оба профиля отдельно.
5. Выберите режим **VPN** через быстрые настройки или **Settings → Inbound → Service mode**. System proxy может не охватывать все программы.
6. Выберите профиль и нажмите кнопку подключения. Выполните системные запросы Hiddify на добавление VPN и разрешение расширения. В [релизе 5.5.5](https://github.com/hiddify/hiddify-app/releases/tag/v5.5.5) заявлено новое VPN system extension; конкретные окна зависят от версии macOS и способа установки. Следуйте запросам именно установленного Hiddify.
7. Дождитесь статуса **Connected** и проверьте видео в браузере и Telegram. Если приложение просит привилегии или сообщает ошибку расширения, сохраните текст и версию macOS для поддержки. Старую инструкцию запуска GUI через `sudo` не применяем автоматически к новой реализации расширения.
8. Отключайте VPN большой кнопкой перед сменой профиля. На базовом тарифе завершите подключение на предыдущем устройстве.
