# Hiddify на iPhone и iPad

Нужен **iOS / iPadOS 15.5 или новее** — это требование актуальной страницы Apple. Название приложения: **Hiddify Proxy & VPN**, разработчик **Holistic Resilience**, App Store ID `6596777532`.

**Если Hiddify недоступен в вашем App Store:** для **VLESS + REALITY в PLUS** воспользуйтесь [отдельной инструкцией Karing](ios-karing.md). Для **Hysteria / BASIC** используйте Hiddify или [напишите в поддержку](https://t.me/andriyshkoy). Безопасный импорт нашего JSON Hysteria в Karing пока не подтверждён; не отключайте проверку сертификата ради подключения.

## Установить

1. Откройте [официальную страницу в App Store](https://apps.apple.com/app/hiddify-proxy-vpn/id6596777532).
2. Нажмите **Загрузить / Get** и подтвердите установку обычным способом. Если магазин сообщает, что приложение недоступно в вашем регионе, проверьте [официальную инструкцию установки](https://hiddify.com/app/How-to-install-Hiddify-app/). Доступность зависит от региона App Store. Файл IPA из релиза не является обычным способом установки на iPhone.
3. Откройте Hiddify, выберите язык и фактический регион. Ознакомьтесь с условиями приложения и самостоятельно выберите настройку аналитики.


## Добавить доступ

4. В боте выберите сервис в **«Мои ключи»**. Для **Hysteria** сохраните `vpn-by-andriyshkoy-hysteria.json` из Telegram на устройство. Если бот прислал JSON текстом, скопируйте весь профиль: первую строку `// profile-title` и JSON целиком. Для **VLESS + REALITY** скопируйте всю ссылку `vless://…`.
5. Переключитесь в Hiddify: **Главная / Home → «+» → Файл / File** и выберите JSON в системном окне файлов. Для скопированного JSON или ссылки VLESS используйте **«+» → Из буфера обмена / Clipboard**. Если iOS спросит разрешение вставить текст, выберите **Разрешить вставку**.
6. Дождитесь профиля. На полном тарифе добавьте JSON Hysteria и ссылку VLESS отдельно; перед каждым импортом выбирайте нужный сервис в боте.

## Разрешить VPN и проверить

7. Выберите профиль и нажмите большую кнопку подключения. В первом системном запросе **Hiddify Would Like to Add VPN Configurations** нажмите **Разрешить / Allow**, затем подтвердите кодом устройства, Face ID или Touch ID, если система это попросит. Это разрешение VPN на устройстве; пароль от Apple ID в боте не нужен.
8. Дождитесь **Connected / Подключено**. Откройте YouTube или Telegram, запустите видео и перемотайте. Для отключения нажмите кнопку ещё раз. Закрытие окна приложения само по себе не является надёжным способом отключить VPN.
9. Если запрос разрешения был отклонён, повторите подключение и проверьте **Настройки iOS → Основные → VPN и управление устройством → VPN**. Названия пунктов зависят от версии iOS. Убедитесь, что другой VPN отключён.
10. При переходе на второе устройство на базовом тарифе сначала отключите первое. При проблемах с Hysteria на полном тарифе попробуйте профиль VLESS + REALITY.
