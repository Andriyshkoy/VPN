# Локальная проверка интерфейса

PNG сняты с настоящего React-приложения через Playwright на локальном Vite. Данные полностью синтетические: аккаунты 42, 57, 68, 79, кошелёк 137,50 ₽ и фиктивная рассылка. На каждом кадре есть отметка DEMO. Кадры не подтверждают работу серверной миграции, биллинга или доставки Telegram.

В harness перехватывается каждый запрос `/api/**`; неизвестные маршруты возвращают ошибку и проваливают проверку. Любые запросы за пределы локального origin запрещены, service worker отключён. Настоящий backend не запускается; даже нажатие кнопки запуска обрабатывается локальной фикстурой. Включение ∞, подтверждение отмены и повтор доставки при съёмке не выполняются. В `capture-report.json` записаны использованные маршруты, ошибки и размеры страниц; `fixtures.json` содержит пример данных без настоящих пользователей и ключей доступа.

Во всех фикстурах рассылок выставлен `delivery_paused: true`. Подтверждение создаёт только очередь: 3 получателя ожидают, отправлено 0. Доставка ждёт отдельного включения оператором; в этой панели такого переключателя нет, harness не меняет feature flags. Пример завершённой рассылки для окна повтора содержит синтетические исторические результаты, а не результат новой очереди. Текущая доставка остаётся выключенной и при просмотре этой истории.

## Повторная съёмка

Из `admin_frontend`:

```sh
npm ci
npm install --prefix /tmp/vpn-product-playwright --no-package-lock playwright@1.65.0
node scripts/capture-product-demo.mjs
```

Harness сам запускает Vite только на `127.0.0.1:4178` и завершает его после съёмки. Для Playwright используется отдельная установка в `/tmp`, зависимости проекта не меняются. Нужен Chromium из кэша Playwright; при его отсутствии:

```sh
/tmp/vpn-product-playwright/node_modules/.bin/playwright install chromium
```

Можно передать `PLAYWRIGHT_MODULE` (путь к `playwright/index.mjs`), `PLAYWRIGHT_CHROMIUM_EXECUTABLE` (путь к Chromium) и `DEMO_PORT`. Скрипт не принимает внешний URL.
