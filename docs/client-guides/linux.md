# Hiddify на Linux

В стабильном релизе **5.5.5** доступны **x86_64** AppImage и DEB. Рабочий стол и библиотеки зависят от дистрибутива; отдельный ARM64 Linux-пакет и RPM среди assets этого релиза не опубликованы.

Локальный иллюстрированный preview содержит наши реальные снимки Linux Hiddify 5.5.5 от 09.11.2026. Он хранится отдельно от публичного репозитория; шаги ниже описывают проверенный интерфейс этой версии. Снимки не подтверждают работу VPN в операторской сети.

## Установить и запустить

1. Скачайте [AppImage x64](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-Linux-x64-AppImage.AppImage) из официального релиза. Для Debian/Ubuntu можно использовать [официальный DEB](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-Debian-x64.deb) и штатный установщик пакетов.
2. В файловом менеджере разрешите выполнение AppImage в свойствах файла. Или в терминале, из каталога с загрузкой:

   ```bash
   chmod +x Hiddify-Linux-x64-AppImage.AppImage
   ./Hiddify-Linux-x64-AppImage.AppImage
   ```

3. Если запуск сообщает об отсутствии FUSE, используйте подходящие пакеты своего дистрибутива или официальный DEB. Для запуска без монтирования AppImage можно распаковать в отдельную папку:

   ```bash
   ./Hiddify-Linux-x64-AppImage.AppImage --appimage-extract
   ./squashfs-root/AppRun
   ```

   Распаковка не исправляет отсутствие GTK и других библиотек: при такой ошибке передайте поддержке имя дистрибутива и точное сообщение.

4. В первом окне выберите язык и фактический регион; настройку аналитики выбирайте самостоятельно.


## Добавить профиль и подключиться

5. Получите профиль сервиса в боте. Для **Hysteria** сохраните `vpn-by-andriyshkoy-hysteria.json` и в Hiddify выберите **Главная / Home → «+» → Файл / File**. Либо скопируйте весь профиль: первую строку `// profile-title` и JSON целиком и используйте **«+» → Из буфера обмена / Clipboard**. Для **VLESS + REALITY** скопируйте целую ссылку `vless://…` и импортируйте через Clipboard. На полном тарифе добавьте оба профиля отдельно.



6. Выберите **Settings → Inbound → Service mode → VPN**, если VPN нужен всем приложениям. System proxy подходит только программам, учитывающим системный прокси.


7. Для режима VPN нужны права управления сетевым интерфейсом. Полностью закройте Hiddify через трей; используйте предусмотренный вашей установкой запрос привилегий. Если приложение прямо сообщает о недостатке прав, официальное руководство также описывает запуск AppImage от root. Запускайте только проверенный официальный файл и не держите одновременно обычный и привилегированный экземпляры. Не запускайте от root браузер или Telegram.
8. Выберите профиль, нажмите кнопку подключения и дождитесь **Connected**. Проверьте видео в браузере и Telegram. Отдельно убедитесь, что соединение используется приложением вне браузера.
9. Отключайтесь кнопкой Hiddify перед сменой профиля. Если после аварийного завершения пропала сеть, снова запустите Hiddify и штатно отключите его; перед ручной правкой DNS/маршрутов сохраните текст ошибки для поддержки.
