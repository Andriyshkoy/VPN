# Hiddify на Android

Нужен Android **7.0 или новее**. Официальное приложение — **Hiddify**, package `app.hiddify.com`.

## Установить

1. Откройте [Hiddify в Google Play](https://play.google.com/store/apps/details?id=app.hiddify.com) и нажмите **Установить**.
2. Если Google Play недоступен, скачайте [официальный universal APK с GitHub](https://github.com/hiddify/hiddify-app/releases/latest/download/Hiddify-Android-universal.apk). Откройте файл в «Загрузках». Если Android спросит разрешение, разрешите установку из этого источника для браузера или файлового менеджера, которым открываете APK.
3. Нажмите **Установить → Открыть**. При первом запуске выберите язык. Регион выбирайте по своему фактическому местоположению — например, Россия для подключения из России. Это настройка клиента, а не выбор страны VPN-сервера. Решение об отправке аналитики остаётся за вами.

## Добавить ключ и подключиться

4. Откройте бота, получите ключ и скопируйте **всю** строку `hysteria2://…`, `hy2://…` или `vless://…`. Если выдана подписка `https://…`, скопируйте её целиком.
5. Вернитесь в Hiddify: **Главная / Home → «+» → Из буфера обмена / Clipboard**. Если система запросит доступ к скопированному тексту, разрешите вставку. Дождитесь появления профиля. На полном тарифе повторите для второй транспортной ссылки.
6. Выберите нужный профиль. В режиме сервиса должен быть выбран **VPN**, чтобы соединение использовали приложения телефона. Нажмите большую кнопку подключения на главной.
7. При первом соединении Android покажет системный запрос на создание VPN-соединения. Подтвердите его. Разрешите уведомление о работе VPN, если оно запрошено: так проще видеть активное подключение.
8. Дождитесь статуса **Подключено / Connected**. Откройте YouTube или Telegram, загрузите видео и перемотайте вперёд. Проверяйте фактическую загрузку, а не только зелёный индикатор. Повторное нажатие большой кнопки отключает VPN.

## Чтобы не отключался в фоне

9. Если связь пропадает после блокировки экрана: **Настройки Hiddify → Общие / General → Disable battery optimization**. Подтвердите системный запрос. На некоторых телефонах дополнительно нужен режим батареи **Без ограничений** для Hiddify в настройках Android.
10. Отключите другой VPN перед повторной проверкой. На базовом тарифе отключите Hiddify на предыдущем устройстве. Если Hysteria не работает в этой сети, на полном тарифе попробуйте VLESS + REALITY.
